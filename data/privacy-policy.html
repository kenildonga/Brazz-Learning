3. Information We Collect

3.1 Device and app identifiers

When You register or open the Application, We may collect and store:

  • Device unique ID — an identifier provided by the Application / Device so We can recognize the same Device across sessions.

  • App unique ID / install ID — an identifier for the Application installation on that Device.

  • Timestamps — when the Device record was created or last updated.

3.2 Push notification token

If You grant notification permission, We may collect a push token (for example, from Firebase Cloud Messaging or a similar provider) so We can send optional notifications. You can disable notifications in Your Device settings; doing so may stop new tokens from being useful but may not automatically delete a token already stored until You request deletion or reinstall/reset.

3.3 Access tokens and deep links

The Service may issue short-lived access tokens (JWTs) containing Device-related identifiers so the Application can call our APIs. If You use a deep link or join token, We process that token only to validate access and update Device state. We do not use deep-link tokens as a substitute for collecting Your name or email.

3.4 Usage and request data

When the Application loads videos, search results, categories, or profiles, our servers may automatically process:

  • API request paths and approximate timing.

  • Search queries You submit in the Application.

  • Technical logs needed to operate, secure, and debug the Service (which may include IP address, user agent, and similar connection metadata as processed by our hosting provider).

3.5 Information We do not require

We do not require You to create an account with Your name, email address, phone number, or payment card to browse the default finance experience. If You contact Us voluntarily (for example, through a contact form or email), We will receive whatever information You choose to include in that message.
